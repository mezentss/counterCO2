# Telegram-бот для расчета выбросов CO₂

Telegram-бот, который рассчитывает выбросы CO₂ для разных видов транспорта между городами.

## Функции

- 📊 **Рассчитать выбросы CO₂** - расчет для всех видов транспорта
- 🌱 **Найти экологичный маршрут** - поиск самого экологичного маршрута с визуализацией
- 📈 **Сравнить маршруты** - сравнение двух маршрутов с графиками
- 🚀 **Старт** - приветственное сообщение
- ❓ **Справка** - информация о боте

## Структура проекта

```
counterCO2/
├── api/                    # API модули
│   ├── co2_calculator.py   # Логика расчета CO₂
│   └── transport_logic.py  # Логика доступности транспорта
├── bot/                    # Telegram-бот (переименован из telegram для избежания конфликтов)
│   └── telegram_bot.py     # Основной файл бота
├── db/                     # Модули базы данных
│   ├── cities_database.py  # База данных координат городов
│   ├── distance_service.py # Сервис расчета расстояний
│   └── emission_calculator.py # Обертка для расчета выбросов
├── utils/                  # Утилитарные модули
│   └── visualizer.py       # Функции генерации графиков
└── requirements.txt        # Зависимости Python
```

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте переменные окружения:
Создайте файл `.env` с содержимым:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота_здесь
```

## Запуск бота

```bash
python3 -m bot.telegram_bot
```

## Зависимости

- python-telegram-bot==20.7
- matplotlib==3.8.2
- numpy==1.24.3
- python-dotenv==0.19.0

## Как пользоваться

1. Запустите бота командой `/start`
2. Нажмите на кнопку с нужной функцией
3. Вводите города по одному в ответ на сообщения бота
4. Получайте результаты с графиками и рекомендациями

## Примеры использования

- 📊 Рассчитать выбросы: Москва → Санкт-Петербург
- 🌱 Экологичный маршрут: Казань → Сочи  
- 📈 Сравнение маршрутов: Москва → СПб vs Казань → Сочи
